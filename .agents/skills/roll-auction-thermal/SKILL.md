# roll-auction-thermal — M7 十一步开机推演

口径全文：`docu/交易员计算流程与逻辑.md` §7；PRD §6b（一步一注释对应 `backend/modules/m7_thermal.py`）。

`火电竞价空间(t) = 负荷 − 水电 − 核电 − 地方燃煤 − 风电 − 光伏 − 联络线 − 非市场化出力`

1. 96 点竞价空间（上式）。
2. 折算空间：平衡时段(10–12/14–16/19–21) 风/光 ×0.8；非平衡不折算。
3. `正备用+调频所需开机 = (正备用 + 调频) / (1 − 受阻)`。
4. `增加备用后所需开机(t) = 折算空间(t) + ③`。
5. `未校验当日最大开机 = max(④)` = 暂定全天开机。**校验 6–10 用未折算空间（扩大安全性）。**
6. `剩余正备用(t) = 暂定开机 × (1 − 受阻) − 未折算空间(t)`；`盈余 = 剩余 − 正备用`；<0 需增机。（业务方 2026-09-10 更正：尾部"− 受阻系数"为笔误已去除）
7. `增机 = |盈余| ÷ (1 − 受阻)`。（业务方 2026-09-10 更正：原 × 为笔误）
8. `剩余负备用(t) = 未折算空间(t) − 暂定开机 × 零价负荷率`；`盈余 = 剩余 − 负备用`；<0 **减机**（v1.7 纠正）。
9. `减机 = |盈余| ÷ (1 − 受阻)`。（业务方 2026-09-10 更正：原 × 为笔误）
10. `验证后开机(t) = ⑤ + ⑦ − ⑨`；逐点钳制 [最小开机方式, 装机 − 检修]。
11. 上半日(1–51 点)/下半日(52–96 点)各取段内 max 为该段最终开机（优先正备用；负备用靠负电价回收）。

负荷率(t) = **未折算**竞价空间(t) ÷ 最终开机(t)；可 >100%（个别点不拦、持续 >100% 警示）；24 点 = 每 4 点平均。双模式：系统推演 / 人工自填并列留痕互不覆盖。缺参 → 默认值 + 黄警示或人工自填。
