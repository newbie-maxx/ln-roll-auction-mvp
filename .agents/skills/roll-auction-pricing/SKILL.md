# roll-auction-pricing — M8 预测/落点/灰度

口径全文：`docu/交易员计算流程与逻辑.md` §8–§10；PRD §6.1 M8（09-08 算法）、附录 E。

## 四步预测（09-08 确定性算法）

- 日期：A = 最新日前出清价日(08-30)；A-1 = 前一运行日(08-29)，需 96 点电价 ≤0 点 ≤48 否则向前回溯；仅约束拟合日 2。
- **步骤一**：`-100 临界空间 = max{ D 日空间(t) : 负荷率(t) ≤ 零价点负荷率 }`。
- **步骤二**：A 日 `k = A 空间最大 ÷ D 空间最大`，归一空间 = A 空间 ÷ k，(归一空间, A 日前电价) 一次拟合 → M1/C1；A-1 日不缩放直接拟合 → M2/C2。
- **步骤三**：`预测1 = M1×D 空间 + C1`；`预测2 = M2×D 空间 + C2`；24 点版独立（24 点空间 = 每 4 点等权平均）。统一钳制 [下限, 上限]（默认 -100/1500）。
- **步骤四**：该点空间 ≤ 临界 → 定价 = 现货下限参数；否则预测 1 全序列最小 < 10（固定）→ 空间 > 临界点整体取预测 2，否则取预测 1。24 点版同规则独立判定。

## 落点区间（相似日唯一用途）

选中时段：检索该时段日前口径负荷率与 D 日计算负荷率差 ≤±5%（可改）的历史日 → 其实时出清价按宽度分档统计概率（分子/分母/统计范围同显）；`期望 = Σ(档中值 × 概率)`；N<3 仅"样本不足"。

## 灰度量价

四字段意向（挂牌价/挂牌量=卖方，摘牌价/摘牌量=买方）两侧独立评估（2026-09-11 业务锁定）：卖方 收益=(挂牌价−最低档两端)×挂牌量(p=首档)、亏损=(最高档两端−挂牌价)×挂牌量(p=末档)；买方 收益=(最高档两端−摘牌价)×摘牌量(p=末档)、亏损=(摘牌价−最低档两端)×摘牌量(p=首档)；任一侧缺价/量 → 该侧不评估。
