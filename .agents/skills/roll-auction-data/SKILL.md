# roll-auction-data — M1 装载与数据底账

口径全文：`docu/交易员计算流程与逻辑.md` §0–§1、§11；PRD §6.1 M1、§7。

## 数据底账

- 日前边界 xlsx（24 sheets）：负荷/水电/核电/地方燃煤/风电/光伏/联络线/非市场化/检修容量/装机容量/火电空间/7日火电空间/1日火电空间/集中式风电/集中式光伏/分散式风电/分布式光伏/地方水电/抽蓄水电/日前负荷率/24点平均日前负荷率/日前电价/日前开机/Sheet1(弃)。
- 实时边界 xlsx（16 sheets）：负荷/水电/核电/地方燃煤/风电/光伏/联络线/非市场化/开机容量/竞价空间/7日火电空间/Sheet1(弃)/实时开机/实时负荷率/24点平均日前负荷率/实时电价。
- 布局：行=日期(2026-08-01…08-31)、列=96 点(00:15…24:00)。
- 省间滚撮 24 点本地缺 → `backend/mock/roll_auction.py` 确定性合成；loader 优先读真实文件。
- 日期角色：D=08-31、A=08-30、A-1=08-29（回溯 08-28…）、历史=08-01…08-30。

## 装载规则（改 loaders/ 前必读）

1. CSV/XLSX/PDF → 统一中间格式 → 校验入库；loader 可替换；全程离线。
2. 省内边界原生 96 点；滚撮 24→96 展开 = 小时值复制 4 份。
3. 标注三类：披露/推断/补齐 + 来源日；水电聚合 = 地方水电 + 抽蓄水电。
4. 运行日不可披露项（非市场化/水电/地方燃煤）→ 最近日法 + 标注来源日。
5. 补齐顺序：人工填数 → 相似日 → 均值/插值；有据标 `▣补齐(方式+依据)`，无据标"缺输入"。
6. 核电预测 = min(最新披露运行日出力, 检修计划出力上限)；检修缺 → 未检修默认开机 + 标注假设。
7. 意向价 >0、24 点、标 `意向`；行数/列不符 → 拒绝入库。

## 参数默认表

调频 1500 / 正备用 3000 / 负备用 400 / 受阻 10% / 平衡系数 0.8（平衡时段 10–12/14–16/19–21）/ 零价点负荷率（系统预测一版可改）/ 最小开机方式 / 装机 28715 / 检修（开机硬上限=装机−检修）/ 现货上限 1500 / 下限 -100 / 区间宽度 100 / ±5% 阈值。全部 `backend/config.py` 单一定义。
