# roll-auction-tieline — M2–M6 联络线链

口径全文：`docu/交易员计算流程与逻辑.md` §2–§6；PRD §6.1 M3/M5/M6、§6.2 M2/M4。

## M2 分布式推断

分布式光伏/分散式风电各挑集中式风光最相近历史日取值，标 `▣取自 M-D`；来源日必须为历史日；查不到 → 标"缺"。

## M3 相似日检索（A 维度）

`A(t) = 省调负荷 − 新能源出力 − 核电出力 − 水电出力 − 非市场化出力 − 地方燃煤出力`（= 火电竞价空间 + 联络线；核电用 M1 min 口径；六项独立不重叠，地方燃煤必减——业务方 09-04 确认）。

- 逐 96 点检索；N≥3 给分布（中位/P25/P75）；N<3 放宽至上一周并标注；跨月标 `▣`。
- 任一项缺 → 先补齐；无据 → 该点位"缺输入"。

## M4 基线

各历史日基线(96) = 滚撮量(24→96 展开) + 日前联络线；缺数日标"缺"不参与均值。

## M5 省间交易总数

= 滚撮量(24→96 展开) + 省间现货；**现货恒等式自算 = 日前联络线 − 实时联络线**（不爬取；"历史日自算省间现货"作边界展示项）。滚撮缺点位 → 仅现货项 + 黄警示。

## M6 预测联络线

`预测联络线(96) = 基线均值 − 省间交易总数`；推断值 + 理由 + 样本来源随行；任一缺 → "缺输入"。
