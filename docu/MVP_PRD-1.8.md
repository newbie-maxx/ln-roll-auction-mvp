## §0 一句话定位

> **【v1.5 双轨前提，务必先读】** 因**省内（公司辅助决策系统接口）与省间（省间滚撮软件）两类外部取数通道当前均不可依赖**，本次 MVP 拆为 **A 轨（主线，做）**与 **B 轨（暂缓，不做）**：**A 轨 = 全部计算链（M1–M9）+ 输出与对照，输入一律来自交易员本地已导出的测试数据**（离线文件，不联网）；**B 轨 = 一切外部数据获取**（省内接口、省间运行日快照 T-1a、省间历史日回查 T-1b、东北传递单备用），**本次一律不做**，T-1a/T-1b 与 P-1a/P-1b 随之**挂起**。A 轨判定改为 **P-1c 计算链口径一致性**（客观层对老 Excel / 人工读数）。**A 轨不回答"外部取数能否自动化"，该问题随 B 轨启动时重开。** 详见 §1.0。
>
> **【v1.7 范围提示】** 业务方 2026-09-07 提出的增强集（需求一~八）在 A 轨定位如下：① 意向挂牌/摘牌价、② 灰度量价评估、③ 火电开机 11 步推演与全套变量、④ 核电出力预测、⑥ 人工修订持久化、⑧ 开机双模式，**均属"在本地数据 + 本地计算链内"新增输入与算法，不引入任何新外部取数，可在 A 轨落地并纳入 P-1c 客观层对照（开机推演、灰度量价、核电预测为客观可复算算式）**；⑤ 气象平台接口、⑦ 边界曲线可视化，属**展示/交互增强**——气象接口仅**预留接入位（本次不接公网，光照/温度作 A 维度外的可选输入占位）**，曲线可视化由 **M9「决策工作台」产品 UI** 承载（见 §5.4a；一屏三栏布局 + 24 时段展开右滑面板 + 96 点边界曲线与局部修改 + 披露/测算双色 + 智能助手对话框），**完全离线运行（不连公网、不出内网）**，因此 **NG-M7"不做页面"约束在 v1.7 反转**（MVP 提供 M9 决策工作台 UI，交易/申报类业务前端仍不做；详见 §5.3 / §5.4）。

面向辽宁售电侧滚撮场景，以**省间数据能否自动化取到（T-1a/T-1b）**为唯一硬不确定点（**v1.2：两类数据同为「省间滚撮软件」一个通道的两种读数——运行日快照 / 历史日回查，通道结论共用**），验证"边界采集 → 标准化 → 相似日样本 → 联络线推算 → 负荷率 → 价格概率"全链**程序化正确性**（**计算链全程 96 点，价格预测 09-07 起含 96 点 + 24 点两版（09-08 重写：96 点与 24 点预测电价 = A/A-1 日线性拟合系数 × D 日 96/24 火电竞价空间 + 步骤四临界判定，不再"以负荷率匹配历史日出清"，见 §1.3/M8）**；程序化正确性的对照口径分两层（v1.1 修订）：**客观层**（披露输入、96 点换算与 24→96 展开、样本组成员、基线算式、快照读数）与老 Excel / 人工读数做**一致性对照**；**预测层**（联络线预测、负荷率预测、新能源/分布式推断及下游价格概率）不对老 Excel 交易员预测值（因人而异、主观性大），验收对照**事后实况**（实时市场实际结果）。产品收窄为 UC1–UC9 全链标准口径 + M9「决策工作台」产品 UI（离线运行，§5.4a），不做交易/申报类业务前端（NG-M7）、不做复盘与 P1/P2 功能。**（v1.7：M7 火电开机、M8 灰度量价、核电预测等新增/修订算式属客观可复算对象，纳入 P-1c 客观层对照；09-08：+ M8 电价预测拟合（临界空间/M1·C1/M2·C2/预测 1·2/步骤四）与落点区间算式；M9 产品 UI 与气象接口属 A 轨本地展示/交互增强，见 §0 上条）**

## §1 技术路线（第 1 步）

### 1.0 双轨范围定义（v1.5 新增，业务方 2026-09-04 拍板）

> 起因：**省内数据经公司辅助决策系统接口自动获取目前也存在问题**，省间滚撮软件通道亦未验证（有反爬、无已知现成方案）。为不让"取数通不通"卡死计算链验证，本次把 MVP 拆成两条轨道。

| 轨 | 包含范围 | 本次是否做 |
|---|---|---|
| **A 轨（MVP 主线）** | **M1–M9 全部计算链 + M9「决策工作台」产品 UI（§5.4a，离线）+ 逐日对照报告**；输入 = **交易员本地已导出的测试数据**（离线文件，96 点为主，省间滚撮为 24 点） | **做**——本次唯一交付物与唯一判定对象 |
| **B 轨（暂缓）** | **一切外部数据获取**：① 省内辅助决策系统接口对接（历史 + 运行日，原 D-1/D-2）；② 省间滚撮软件**运行日快照抓取**（原 T-1a）；③ 省间滚撮软件**历史日回查**（原 T-1b）；④ 东北电力交易中心传递单 PDF 备用通道 | **暂不做**——通道就绪后另立验证；**T-1a / T-1b 与 P-1a / P-1b 一并挂起** |

**A 轨口径（实现约束）**

1. **数据来源**：本地导出文件（**CSV / XLSX / PDF 多格式，v1.6**；绝对路径与文件清单见 §7 **A-0**，**路径待业务方提供**）。M1 的 loader 统一解析三种格式 → **中间格式（标准 CSV/内部表）→ 校验 → 96 点入库 → 三类标注**；**不做任何抓取、不联网、不调接口**。解析库选型放开为**内网可安装的开源库**（如 openpyxl 等，见 §8），维持离线部署、数据不出内网。**（v1.7 注：人工可输入的"意向挂牌/摘牌价、火电开机参数（调频/正负备用/受阻系数/新能源平衡系数/零价负荷率/最小开机方式/辽宁装机容量/检修计划）"属配置/意向输入，不属外部取数，均计入本约束，支持本地录入并持久化，见 §7 参数表与 §6 存储设计。）**
2. **粒度不变**：省内边界按 96 点入链；省间滚撮为 24 点，入链前 **24→96 展开（同小时值复制 4 份）**；96→24 合成仍为"每 4 点算术平均"。
3. **ingest 可替换（不留技术债）**：M1 的取数层保持**可替换 loader** 设计——A 轨实现为"本地文件 loader（多格式）"，B 轨只需替换 loader 实现即可接入接口/抓取，**计算链代码零改动**。
4. **判定**：A 轨只判 **P-1c 计算链口径一致性**（客观层：96 点换算与展开、样本组成员、基线算式、快照解析读数 vs 老 Excel / 人工读数）；**P-1a / P-1b 挂起**，不占本次判定日（§3）。**（v1.7 注：M7 火电开机推演、M8 灰度量价、核电预测出力等新增算式为客观可复算对象，纳入 P-1c 对照范围，见 §3。）**
5. **主指标口径调整**：A 轨内"边界处理耗时 35~45 分钟 → ≤10 分钟"按**本地数据入库后的计算链耗时**度量，**不含取数环节**（取数耗时随 B 轨单独评估）；对照报告中须注明该口径差异。
6. **缺数补齐（v1.6）**：边界数据（运行日/历史日）缺数按"**人工填数 → 相似日代替 → 平均值/插值**"顺序补齐（默认顺序可配置），补齐值标注 `▣补齐(方式+依据)`（如 `相似日取 M-D`、`均值·插值(窗口 N–M)`）；**有据可补则补，无据才标"缺输入"**，补齐值属非披露类、不得冒充披露值（场景 PRD §0 硬约束 5）。
7. **P-1c 对照口径（v1.6）**：程序补齐点位对照时**对齐老 Excel 补齐口径**；老 Excel 未补而程序补（或反之）→ 计入对照报告"口径差异清单"单独说明，**不计入一致性不达标**（§3 P-1c）。

**B 轨保留内容（不废弃，仅暂缓）**：§2（T-1a/T-1b 事实与试金石）、§4.2–§4.5（退路与换线条件）、§7 D-1~D-5/D-8/D-9（外部依赖）、§9 原任务 2/8/9（通道摸底与实测）——**全部原样保留并标注"归 B 轨"**，B 轨启动时直接复用，无需重写。

### 2.4 两卡角色差异

- **T-1a（运行日快照）**：当日链路必需、时效敏感（开市期间要用）；若不过，当日预测无法闭环，是最关键一张。
- **T-1b（历史日回查）**：喂相似日基线，**时效容忍度高**（可提前批量回捞）；若不过，影响基线质量而非当日取数。
- **隐含判断（v1.2 更新，原判断已失效）**：原文为"T-1b 存在可行解只是没验证；T-1a 才是'有没有解都不知道'的一张"。现两卡共用同一软件通道，**T-1a 成为 T-1b 的前置探针**：T-1a 摸底通过 → T-1b 只需验证"历史回查范围 + 数据是否事后修订"两件事；T-1a 不通过 → T-1b 同步转人工兜底，**不再另起 PDF 解析方案**（原方案随东北平台权限问题一并搁置）。
- **风险提示**：通道收敛的收益是**少做一整套 PDF 解析、不再依赖东北平台下载权限**；代价是**单点依赖上升**（软件改版/反爬升级同时影响两类数据），故 §4.3 保留"东北传递单备用通道"作为对冲。

## §4 备选路线（第 4 步）

### 4.1 总体判断与切换原则

**④ 时段选中、修订的高亮与并存规则**

- **选中时段标红 = 选中指示（与可改性分离）**：选中某 24 点时段 → 该时段对应曲线段**标红**（可改边界、负荷率、预测电价、电价区间/期望、灰度量价收益一律标红指示该时段）；可改边界数值格中该时段那 **4 个 96 点可改并标红**，其余 92 点只读；**只读曲线（负荷率/预测电价/灰度量价收益）该时段点仅标红指示，无数值格编辑入口**。
- **修改只发生在"可改边界"**：修改某边界 → **修改前曲线 + 修改后曲线并存**；修改后曲线**特殊色**（原=蓝/黑、修订=橙/绿、选中=红）；可改边界的数值格并列显示 **原值 / 新值 / 修改理由（≥5 字）**；数据走附录 D 分层存储，**原值永不覆盖、可回退**。**只读曲线/数值格不存在修订并存**——它们由联动重算整体刷新，不落人工修订。

**⑤ 修改联动（09-08 口径）**：任意改动（全局参数，或某时段可改边界/意向价/现货上下限/区间宽度/±5% 阈值/零价点负荷率）→ 该点/该时段**联动重算** → **96 点边界曲线 → 96 点负荷率（+24 点合成）→ -100 临界火电竞价空间与拟合系数重算 → 96/24 点预测电价（M×D 日空间 + C + 步骤四）重出、电价落点区间概率、电价期望、灰度量价最大/最小收益及概率（相似运行日按 ±5% 检索、24 点口径）**即时刷新（对齐 §8"单点重算 ≤ 1 秒"）。只读输出仅在本次联动中刷新，不接受直接人工编辑。

- **用户故事**：作为交易员，我希望把**本地已导出的测试数据**读进系统就自动就绪、**按 96 点保留原始粒度**（口径统一、来源可辨），直接进入测算；将来换真通道（接口/抓取）时**只换装载来源、不动计算**。作为交易员，我希望能录入**当日滚动撮合意向挂牌/摘牌价格**与**火电开机所需参数**，且这些人工输入能被系统妥善保存、需要时能改回原值（v1.7）。
- **数据来源（A 轨，v1.6 多格式）**：**交易员本地已导出的测试数据文件**——支持 **CSV / XLSX / PDF**（CSV 默认 UTF-8 with BOM），省内边界 **96 点**、省间滚撮 **24 点**；**绝对路径与文件清单见 §7 A-0，路径待业务方提供**。**loader 统一解析**：三种格式 → 标准中间格式 → 校验入库，各模块只消费中间格式（格式解析库内网安装，见 §8）。**B 轨（暂不做）**：公司辅助决策系统接口（v1.2 口径）与省间软件抓取。本模块 **loader 可替换**：A 轨实现"本地文件 loader（多格式）"，**B 轨仅替换 loader 实现即可接入外部通道，计算链代码零改动**。
- **业务流程**：**读取本地导出文件（CSV/XLSX/PDF → loader 解析为中间格式）→ 解析校验（字段映射确认、行数 = 96/24 按源披露粒度）→ 96 点入库**（省内边界原生 96 点；省间滚撮 **24→96 展开：24 点值复制 4 份**）→ **运行日不可披露项按最近日法入链——非市场化出力 / 水电 / 地方燃煤出力，均取本地导出中"最近披露数据"近似替代运行日值并标注来源日**（同场景 PRD §1.2 第 1 步口径）→ **缺数补齐（v1.6）：仍有缺数的点位按"人工填数 → 相似日 → 均值/插值"给出建议补齐值并标注 `▣补齐(方式+依据)`，交易员可确认/改人工填数/置缺输入** → 三类标注（披露值/推断值/补齐值/来源日）→ 状态绿/黄 → 供 M3 起用。**（v1.7 补充装载项）**：① **意向挂牌/摘牌价**（人工录入，24 点，默认整日同值可改，标注 `意向`）；② **火电开机参数**（调频容量、正备用、负备用、受阻系数、新能源平衡系数、火电检修计划、零价负荷率、最小开机方式、辽宁火电装机容量，默认值见 §7 参数表，可改并留痕）→ 供 M7；③ **核电边界**：装入核电披露出力（运行日最近披露）+ **核电检修计划**，为核电预测提供输入（见下）。**全程不联网、不调接口、不做抓取。**
- **核电出力预测逻辑（v1.7 需求四，完善）**：核电边界在滚动撮合日当日的出力预测 = **min( 核电最新披露运行日出力 , 核电检修计划定义的出力上限 )**——即"预测出力 ≤ 最新披露运行日实际出力"（不在检修期以最近披露实绩为上限，避免高估），且 **≤ 当日检修计划允许的出力上限**（检修期按检修压出力）；检修计划未覆盖某机组时，该机组出力上限 = 额定/披露出力。取二者最小者作为核电预测出力入链，并标注其取值依据（`最近披露 M-D` / `检修上限`）。**历史日核电**按各自披露值入链；核电检修数据如缺（D-6）→ 未检修默认开机（额定出力）+ 标注假设（沿用既有兜底）。
- **业务规则**：**原始数据按 96 点留存，不提前降 24 点**（降 24 点仅发生在负荷率合成 96→24 与 **24 点价格预测**环节；**96 点价格预测在 96 点原生做**，09-07 双粒度）；任一边界（披露/推断）可人工修正，**修正必填备注（≥5 字）**；推断值/补齐值不得冒充披露值；**边界缺数按补齐策略处理——有据可补（人工填数/相似日/均值·插值）则补并标注方式+依据，无据才标"缺输入"**（v1.6，场景 PRD 硬约束 5）；文件缺列/行数不符 → **拒绝入库**并提示差异项；**人工意向/参数输入纳入持久化（原值保留，修订分层，见 §6 存储设计 / 附录 D）**。
- **状态流转**：文件未提供(灰) → 解析中(加载) → 校验通过(绿) / 文件缺失或点位不全(红，提示缺项) / 运行日项缺失(黄警示，不阻断)。
- **穷尽异常**：①本地文件缺失/路径不对 → 提示缺文件并列出缺项；②解析失败（含 **XLSX/PDF 加密/损坏/格式不符，v1.6**）→ 提示不入库、点位不全 → 红，可转 CSV 重导；③换算前校验不过 → 标"缺"不参与计算；④滞后替代/推断值必须标注来源日，漏标注 = 展示缺陷；⑤缺数点位**无任何依据可补** → 不自动补、标"缺输入"；⑥补齐建议值被交易员确认后改动 → 按人工修正留备注（≥5 字）；⑦意向挂牌/摘牌价非数值或越界（如 ≤0）→ 拒绝并提示（v1.7）；⑧核电检修计划缺 → 按"未检修默认开机（额定/最近披露出力）+ 标注假设"处理（v1.7）。
- **UI 要点**："数据就绪清单"文件输出（每文件：来源路径/就绪状态/粒度/标注/缺失项；**v1.7：含人工意向价与开机参数清单**），交易员确认后触发计算。
- **验收（GWT）**：Given 本地导出文件齐备 When 执行装载 Then 96 点全有省调负荷/集中风光/水电/**地方燃煤出力**且保留原始 96 点（抽查 2 时段复核与源文件一致；**地方燃煤运行日不披露时取源文件中最近披露值替代入链并标注来源日，缺标注 = 展示缺陷**）；省间滚撮 24 点展开 96 点 = 原 24 点值复制 4 份（抽查 1 小时复核）。Given 本地文件为 XLSX 或 PDF When 装载 Then 解析入库结果与同内容 CSV 一致（抽查 1 时段复核，v1.6）。Given 某边界点位缺数 When 装载 Then 按补齐策略（人工填数→相似日→均值/插值）给出建议补齐值并标注 `▣补齐(方式+依据)`，无据可补 → 标"缺输入"（v1.6）。Given 某文件缺失 When 装载 Then 提示缺文件与列缺项。Given 粘贴多行 When 解析 Then 行数 = 96 或 24（按源披露粒度）、字段映射确认一致才入库，不一致提示错误。Given 程序补齐而老 Excel 未补（或反之）When 出对照报告 Then 该点位计入"口径差异清单"单独说明、不计入不达标（v1.6）。**Given 装载全程 When 运行 Then 无任何联网/接口/抓取调用（纯本地文件读取，可审计）。** Given 录入意向挂牌/摘牌价 When 校验 Then 非数值/越界被拒、正常录入入库并标 `意向`（v1.7）。Given 核电检修计划与最近披露出力 When 计算核电预测 Then 输出 = min(最近披露运行日出力, 检修计划出力上限)，未检修机组以上限=披露出力计并标注假设（v1.7）。Given 人工修改某边界 When 持久化 Then 原值保留、修订值分层存储、可回退并可溯源（v1.7，见附录 D）。

#### M3 相近样本组检索（= UC3）——与老 Excel 对照的核心
- **用户故事**：作为交易员，我希望每个 96 点点位能看到与当日最像的历史样本组（数量/成员/跨月/放宽），且结果和我老 Excel 算得一致才敢信系统。
- **A 维度算式（v1.4，同步场景 PRD v1.5；业务方 09-04 更正）**：**A(t) = 省调负荷 − 新能源出力 − 核电出力 − 水电出力 − 非市场化出力 − 地方燃煤出力**（= 火电竞价空间 + 联络线出力，联络线项被消去，历史日与运行日两侧均可直接计算）。**原式少减了「地方燃煤出力」，本次补入**；地方燃煤出力**运行日当日不披露**，按**最近日法**取最近一期披露值近似替代并**标注来源日**（与非市场化、水电完全同口径），**历史日侧按各自披露值入链**（**披露粒度 = 96 点，入链无需再做粒度换算；且未被"非市场化出力"包含、两者独立不重叠，A(t) 中两项均减——业务方 09-04 确认**）。**口径变更影响：样本组检索结果与下游基线一律以新 A 值为准，此前基于旧 A 值的对照/回测结论作废、须以新口径重跑。**（**v1.7 注：M3 的 A 维度中"核电出力"采用 M1 核电预测（min(最近披露,检修上限)），与边界装载一致，避免核电口径二义。**）
- **业务流程**：M1 数据齐备 → **逐 96 点点位**按 A 维度与新能源维度各筛一组 → 显示 N、成员、分布（中位/P25/P75）、跨月标注 → N<阈值自动放宽至上一周并标注 → 供 M4/M6。
- **业务规则**：双维度各出一版（标准口径）；检索**按 96 点逐点执行**（基线、联络线下游均为 96 点）；**A(t) 六项缺任一项 → 先按缺数补齐策略处理（v1.6：人工填数 → 相似日 → 均值/插值，标注方式+依据），仍无据才标"缺输入"、不产无标注猜测值**（含地方燃煤出力）；跨月样本 `▣` 标注；放宽必须标注"已放宽+统计范围"；N≥3 才给分布。
- **状态流转**：无输入(灰) → 检索中 → 有结果(正常) / N<3(提示样本不足+放宽选项，不出概率) / N=0(无样本)。
- **穷尽异常**：①运行日/历史缺 → "无输入"；②—；③N<3 → 不出概率、给放宽选项；④跨月/放宽标注缺失 = 展示缺陷。
- **UI 要点**：每点位样本组清单（版本/N/成员日期/是否放宽）+ 与老 Excel 对照表。
- **验收（GWT）**：Given 数据齐备 When 对 96 点点位检索 Then 输出两版本、每组有 N 与成员，N≥3 给分布。Given 边界齐备 When 计算 A(t) Then **A(t) = 省调负荷 − 新能源出力 − 核电出力 − 水电出力 − 非市场化出力 − 地方燃煤出力**（v1.4），抽查任意 2 点位算术可复核。Given A(t) 六项任一缺 When 计算 Then 先按补齐策略补齐（有据），仍无据则该点位标"缺输入"、不出值、不产无标注猜测值（v1.6）。Given N<3 When 放宽开启 Then 自动放宽至上一周并标注。Given 老 Excel 同口径 When 对照 Then 成员与 N 逐点一致（回测标准）。

#### M5 省间交易总数（= UC5）——滚撮快照承 T-1a，现货推测带把握（v1.7：并入意向挂牌/摘牌价输入）
- **用户故事**（业务方原话）：作为交易员，我希望省间滚撮实况自动进来、现货推测带把握程度说明，且我改了能留下原因，避免"拍脑袋算数"说不清。**（v1.7）同时希望把当日滚动撮合市场**意向挂牌/摘牌价格**录进去，作为我评估这笔买卖最大能赚/最大会亏的参考基准。**
- **数据获取方式（快照制，最小化）**：省间滚撮实况 = **每 5 分钟定时自动抓取 + 交易员需要时手动触发**；每次记录**抓取时刻**；抓取对象 = 北京软件当前展示的 **24 点成交量价**（省间滚撮披露原生 24 点）；入链前 **24→96 展开：每小时值复制 4 份为 96 点对应 4 个 15 分钟点**。不做逐笔/推送式实时对接。（**A 轨：以本地导出 24 点文件替代抓取，见 §1.0**）
- **意向挂牌/摘牌价输入（v1.7，新增）**：交易员对**拟参与滚动撮合的时段**录入**意向挂牌价（卖方期望）与意向摘牌价（买方期望）**，24 点粒度（默认整日同值可改）；标注 `意向`（非披露非推断），用于 M8 灰度量价；录入必留痕、可修改（附录 D 存储）。
- **业务流程**：快照定时/手动抓取 → 落库（24 点量价 + 抓取时刻）→ 24→96 展开 → 现货辅助推测（带概率/区间把握说明，96 点）→ 交易员确认或更正（更正必填备注）→ 合成省间交易总数（96 点）供 M6。
- **业务规则**：滚撮值必须携带**抓取时刻**（展示"某时刻快照"而非实时推送）；**96 点入链，24 点为披露/快照原生粒度，展开规则 = 同一小时值复制 4 份（1 小时量 = 4×15 分钟段，业务方确认按复制实现）**；现货推测带把握（概率/区间）；**更正备注 ≥5 字必填**；更正后联动重算下游并留痕；某点位未录滚撮值 → **仅用现货项 + 黄色警示**。**意向挂牌/摘牌价非数值或越界（≤0）→ 拒绝；录入后标 `意向`，供 M8。**
- **状态流转**：未抓取/失败(黄警示，可手动重试) → 已抓取(绿，标注时刻) → 24→96 展开 → 现货默认推测 → 人工更正(标注"已人工更正(备注)")；意向价：未录(灰) → 已录(绿，`意向`)。
- **穷尽异常**：①定时抓取连续失败 → 黄警示+提示手动抓取；②更正非数值/备注 <5 字 → 拒绝；③—；④快照缺时刻标注或推测不带把握说明 = 展示缺陷；⑤意向价缺录 → M8 灰度量价仅提示"未录意向价，不评估收益风险"（v1.7）。
- **UI 要点**：快照表（抓取时刻 / 24 点量价 / 96 点展开 / 现货推测及把握 / 更正备注），每次抓取一行；**意向挂牌/摘牌价录入表（时段/挂牌价/摘牌价/`意向`标注）（v1.7）**。
- **验收（GWT）**：Given 每 5 分钟到时 When 自动抓取 Then 落库一次带抓取时刻的 24 点快照，且 96 点展开 = 每小时值复制 4 份（抽查 1 小时复核）。Given 交易员需要 When 手动触发 Then 立即抓取并记录时刻。Given 现货推测 When 更正 Then 备注必填、重算并标注"已人工更正"。Given 老 Excel 同刻数据 When 对照 Then 快照值逐时段一致。Given 录入意向挂牌/摘牌价 When 校验 Then 非数值/越界被拒、正常录入入库标 `意向`（v1.7）。

#### M6 预测联络线（= UC6）——MVP 考核量产出
- **用户故事**：作为交易员，我希望预测联络线每个 96 点点位都能看到"由哪些样本日的基线扣了多少省间数得出"（系统给一版预测 + 理由），如果我不同意，能直接改这版预测并写下我的理由，方便日后对比谁更准。
- **业务流程**：基线均值（M3/M4）− 省间交易总数（M5）→ **96 点预测联络线**（推断值）→ 中间值与样本来源随行输出 → **交易员可修改预测并附理由，系统版与修订版并列留痕**（v1.1）。
- **业务规则**：预测联络线 = 基线均值 − 省间交易总数（恒等式，两侧可复核）；**全程 96 点**（基线 96 点、省间数经 24→96 展开后同为 96 点）；输入取**该点位所属的最新快照滚撮值**（快照制下与逐点位算式不脱节）；未录点位按 UC5 规则仅用现货项+警示，**不把"0 成交量"当"已成交 0"**、不产生猜测值；输出必须标 `推断值` 并附理由；**人工修改必填理由（≥5 字），修改后标注"已人工修改(理由)"并联动重算下游**。
- **状态流转**：输入齐 → 计算 → 出值(推断标注+理由) / 缺输入(该点位"缺输入") / 空样本(不出值)。
- **穷尽异常**：①基线或省间任一缺 → 该点位"缺输入"；②—；③除零/空样本 → 不出值；④推断标注、理由或中间值不可追溯 = 缺陷。
- **UI 要点**：预测联络线表（96 点点位/数值/推断标注/理由/基线均值/省间数/样本来源）+ 与老 Excel 客观层对照。
- **验收（GWT）**：Given 基线与省间齐备 When 计算 Then 输出 96 点预测联络线 = 基线均值 − 省间交易总数且可追溯每点位样本来源。Given 任一缺 When 计算 Then 不输出数值、标"缺输入"。Given 运行日后实况实时联络线已入库 When 对照 Then 输出逐点位误差（预测 vs 实况，v1.1：不对老 Excel 预测值）。Given 交易员修改预测 When 提交理由 Then 理由≥5 字、留痕并列展示；理由为空则拒绝。

#### M8 意向时段价格预判与概率（= UC8）——技术路线终点（v1.7：并入灰度量价评估；**09-08 重写：电价预测改为"临界空间判定 + A/A-1 线性拟合两版"确定性算法，剔除原"电价预测参考相似日出清价"口径**）
- **用户故事**：作为交易员，我希望预测 **D 日（待预测交易日）** 的电价——**已知数据库中最新日前出清价已更新至 A 日**，用 D 日 96 点火电竞价空间/火电开机得出负荷率，先取 **-100 临界火电竞价空间**，再分别用 **A 日（放缩后）与 A-1 日（不缩放）** 拟合"火电竞价空间→日前电价"的一次函数（M1/C1、M2/C2），对 D 日给出 **96 点与 24 点两版电价预测 1/2**，按步骤四定最终电价；同时希望得到**选中时段在历史相似运行日（负荷率 ±5%，默认可改）下的实时出清价落点区间与概率**、**按落点概率加权的期望电价（v1.7）**，并结合我录入的意向挂牌/摘牌价与交易量，估算这单买卖**带灰度的最大收益/最大风险（价格与金额区间 + 概率）**，好决定量价怎么报。
- **【09-08 口径更正：剔除"电价预测参考相似日"】**
  - 原口径（v1.1 补充二/09-07 双粒度）"以 96/24 点负荷率匹配历史日出清价、取相似日 96/24 点出清作为预测电价"**有误、剔除**——电价预测不再依赖相似日匹配，改为上述确定性拟合算法。
  - **相似日仅在"电价落点区间"统计中使用**：计算得到 D 日负荷率后，对交易员选中的时段，检索历史日中该时段**日前口径负荷率与计算负荷率相差不超过 ±5%**（阈值默认 5%，交易员可改；原 ±3% 上调）的运行日，再看这些运行日该时段**实时出清价**落在各档区间的概率。
  - 历史日"日前口径负荷率"数据来源 = 公司辅助决策系统接口获取（接口规格未到前走 A-0 本地导出 CSV 兜底）；历史日侧需备有 96 点与 24 点日前口径负荷率，24 点由 96 点合成。
- **A 日 / A-1 日定义（09-08）**：**A 日 = 数据库中最新日前出清价所在日**；**A-1 日 = A 日的前一运行日**（注：A-1 日**电价 ≤0 的点不应超过 48 点**，若超过则再往前取一天（A-2、A-3…），以此类推，直到满足"电价 ≤0 的点 ≤48 点"再作为拟合日 2。**判定按 96 点粒度逐点计、仅约束拟合日 2（A 日不设限）——09-08 何金泽确认**）。
- **电价预测算法（09-08 新增；客观可复算，纳入 P-1c 客观层对照）**：
  - **输入**：D 日 96 点火电竞价空间与火电开机（M7/§6b 产出）；零价点负荷率（**D 日开机计算中允许手动输入**，沿用 M7 参数，默认系统按相似运行日出清预测一版、交易员可改；**口径注（v1.8 确认）：名称沿用"零价点负荷率"，用途 = 低于该负荷率的点预计按现货市场出清价格下限（默认 -100）定价，即火电报价跳变至下限的临界边界**）；A 日/A-1 日（含回溯）96 点火电竞价空间与 96 点日前出清价（历史数据）。
  - **步骤一：取 -100 临界火电竞价空间**。用 D 日 96 点火电竞价空间 ÷ 火电开机得出 **D 日 96 点负荷率**；找出其中 负荷率 ≤ 零价点负荷率 的点，取这些点**火电竞价空间的最大值**，作为 **-100 临界火电竞价空间**（该值以 D 日空间口径衡量，低于它的点预计将按现货市场出清价格下限（默认 -100）定价）。
  - **步骤二：拟合电价跳变函数（两版）**。
    1. **拟合日 1 = A 日（放缩）**：取 A 日 96 点火电空间最大值与 D 日 96 点火电空间最大值，**放缩系数 k = A 日火电空间最大值 ÷ D 日火电空间最大值**；对 A 日 96 点逐点 `A 日归一火电竞价空间 = A 日火电竞价空间 ÷ k`；对 **A 日归一火电竞价空间 vs A 日 96 点日前电价** 做一次线性拟合 → **一次系数 M1、常数项 C1**。
    2. **拟合日 2 = A-1 日（回溯满足"电价 ≤0 点 ≤48 点"条件；不缩放）**：对 **A-1 日原始火电竞价空间 vs A-1 日 96 点日前电价** 做一次线性拟合 → **M2、C2**。
  - **步骤三：两版电价预测（96 点 + 24 点各两版）**：对 D 日 96 点：`电价预测1 = M1×D 日火电竞价空间 + C1`；`电价预测2 = M2×D 日火电竞价空间 + C2`。对 D 日 24 点：同一公式，但**火电竞价空间先由 96 点变 24 点（每 4 点取加权均值，MVP 按等权算术平均落地，权重口径登记附录 E 复核）**，代入得 **24 点电价预测1/预测2**。
  - **步骤四：D 日最终电价预测（逐点判定）**：对每个点（96 点逐点判定；24 点版以 24 点空间与 24 点预测 1/2 执行同一规则）：
    1. 若该点 D 日火电竞价空间 ≤ -100 临界火电竞价空间 → 该点电价定义为**现货市场出清价格下限参数值**（默认 -100，可改；与钳制同源，v1.8 回改原"固定 -100"口径）；
    2. 否则看 D 日 96 点电价预测1 中**所有预测电价的最小值是否 < 10**（固定值，不随参数联动）：
       - 若 <10 → 火电竞价空间 > -100 临界火电竞价空间的点**取 D 日 96 点电价预测2 的值**；
       - 若 ≥10 → 该点取 D 日 96 点电价预测1 的值。
    输出：D 日最终预测电价（96 点 + 24 点两版，只读输出）。
  - **钳制（09-08 何金泽确认）**：预测 1/2 与最终电价统一钳制在 **[现货市场出清价格下限, 现货市场出清价格上限]**（默认 -100/1500，随参数可改），越界值取边界值。
  - **口径已确认（09-08 何金泽复核拍板；临界定价一项 v1.8 回改，登记附录 C）**：① A-1 日拟合不缩放（M2/C2 直接套 D 日空间）；② **步骤四临界点电价 = 现货市场出清价格下限参数**（默认 -100、可改，与钳制同源；v1.8 回改"固定 -100"），**<10 判定值固定**（不随参数联动）；③ 电价落点统计用**实时出清价**、与预测拟合用**日前电价**的口径并存属业务有意，维持现状；④ 96→24 四点加权当前按等权算术平均落地；⑤ 24 点版按 24 点空间 + 24 点预测 1/2 执行同一规则**独立判定**（与 96 点版各自独立，不强制 24 点 = 96 点聚合）；⑥ A-1（拟合日 2）"电价 ≤0 点 ≤48 点"按 **96 点粒度**判定且**仅约束拟合日 2**（A 日不设限）；⑦ 步骤四"预测 1 全序列最小 <10 → 取预测 2"为**整体切换**（空间 > 临界的点统一取预测 2）。
- **电价落点区间预测（09-08 新增；相似日的唯一用途）**：
  - **新增输入（交易员可改，默认值见 §7 参数表）**：**现货市场出清价格上限（默认 1500）**、**现货市场出清价格下限（默认 -100）**、**区间宽度（默认 100，可选定）**；相似日负荷率阈值（默认 ±5%，可改）。
  - 计算得到 D 日火电竞价空间、火电开机与负荷率后，对**交易员选中的某一时段**（24 点口径）：在**交易员选定的历史日范围**内检索运行日，其**该时段日前口径负荷率与 D 日计算负荷率相差 ≤±5%（默认）**；取这些运行日**该时段实时出清价**，以选定区间宽度将 **[出清价格下限, 出清价格上限]** 划分为等宽档位，统计实时出清价落在每一档的**概率**（分子/分母 + 统计范围）；**电价期望 = Σ(各档区间中值 × 该档概率)**。
- **灰度量价（最大收益/最大风险，v1.7 并入 M8；09-08 明确区间口径）**：
  - 输入：意向挂牌价/摘牌价（M5）、交易量（人工录入）、上述电价落点区间与概率（同一检索、同一口径）。
  - **最低落点区间 = [现货市场出清价格下限, 下限 + 区间宽度]**（贴下限的首档，即该时段历史相似边界下的最低电价区间）；**最高落点区间 = [上限 − 区间宽度, 现货市场出清价格上限]**（贴上限的末档）；两者的**概率 = 该档位落点概率**（与电价落点区间概率一致，可为 0）。
  - **最大收益/最大风险价格区间 = 最低/最高落点区间的两端与意向挂牌/摘牌价相减**；**× 交易量 = 带灰度的最大收益/最大风险金额区间**；**概率与电价落点区间概率相等**。
  - 方向语义（沿用原登记）：挂牌（卖）/摘牌（买）买卖方向对收益亏损的符号，以滚撮"价差撮合"方向口径为准，业务方校正后锁定（登记 §5.6 / 附录 E"灰度量价"复核点）。
- **修改联动重匹配（09-08 更新）**：交易员可修改任一边界（含 A 日/A-1 日选择、零价点负荷率、现货上下限/区间宽度/±5% 阈值、意向价、开机参数等）→ 全链重算 → D 日空间/负荷率变 → -100 临界空间与拟合系数、预测 1/2、最终电价重出；落点相似运行日按新负荷率与阈值重检索，区间概率/期望/灰度量价随新落点重出。修改留理由（≥5 字），系统版/修订版并列留痕（v1.1）。
- **业务流程**：M7 等边界齐备 → D 日 96 点空间与 96→24 合成 24 点空间 → 步骤一（零价点负荷率 → -100 临界空间）→ 步骤二（A 放缩拟合 M1/C1、A-1/回溯不缩放拟合 M2/C2）→ 步骤三（96/24 点预测 1/2）→ 钳制 [下限, 上限] → 步骤四（最终电价 96/24 两版，24 点版独立判定）→ 输出决策依据（主页面 96+24 平铺）；选中时段：±5% 相似运行日检索 → 实时出清价落档统计（区间概率 + 期望）→ 灰度量价（最低/最高落点档 + 意向价差 × 量 + 概率）→ 一并输出。
- **业务规则**：-100 临界空间按"负荷率 ≤ 零价点负荷率的点中火电竞价空间最大值"取；放缩系数 k = A 日空间最大 ÷ D 日空间最大；A-1 拟合不缩放；A-1（回溯日）须满足"电价 ≤0 的点 ≤48 点"（96 点粒度）；**预测 1/2 与最终电价统一钳制在 [现货市场出清价格下限, 上限]（默认 -100/1500，越界取边界值，09-08 确认）**；预测电价 96/24 两版均只读（24 点版按 24 点空间与预测 1/2 同规则独立判定）；电价落点/期望/灰度量价按 24 点输出（区间概率对选中时段 24 点口径）；区间宽度正整数可选定、倒序/负值拦截；分子分母与统计范围必须同显，缺一不展示；N<3 不出概率，仅"样本不足"。
- **状态流转**：样本空(不展示概率) → 生成中 → 概率输出(正常) / N<3("样本不足") / 区间非法(拒绝)；A/A-1 日前电价缺 → 该版拟合缺、提示。
- **穷尽异常**：① 样本组无数据 → 概率区不展示；② 区间非法 → 拒绝；③ N<3 → 不出百分比；④ 统计范围/所选历史日范围缺一不展示；⑤ 边界/参数被交易员修改后未重算 → 提示"输入已变更，需重新计算"（防陈旧结论）；⑥ 意向价/交易量未录 → 灰度量价提示"缺意向价/量，不评估收益风险"（v1.7）；⑦ A 日/A-1 日 96 点日前出清价或火电空间缺 → 拟合日 2 继续向前回溯或标"缺输入"；⑧ 零价点负荷率未录 → 无法取 -100 临界空间，按缺参处理（黄警示，可人工自填）。
- **UI 要点**：**96/24 点预测电价曲线 + 数值格（只读）**（主页面 96+24 平铺；右滑面板 96 点 + 本时段 24 点对照）；选中时段**电价落点区间与概率表、电价期望**、**灰度量价（最低/最高落点档、意向挂牌/摘牌价、交易量、最大收益/最大风险价格与金额区间、概率、分子分母、统计范围）**；参数入口：零价点负荷率、现货上下限、区间宽度、±5% 阈值（全局参数表单，可改并留痕）。
- **验收（GWT）**：Given A/A-1(回溯) 日与 D 日 96 点空间、A/A-1 日前电价齐备 When 拟合 Then M1/C1（A 放缩）、M2/C2（A-1 不缩放）可复算（抽查 1 日复核）。Given D 日 96 点空间 When 计算 Then 96 点预测 1/2 = M×空间 + C 逐点可复核；24 点预测用 96→24（每 4 点均值）空间代入同公式（抽查 2 时段复核）。Given 某点空间 ≤ -100 临界空间 When 步骤四 Then 该点定价 = 现货市场出清价格下限参数（默认 -100，v1.8 确认）；预测1 全点最小 <10 → 空间>临界的点整体取预测2，否则取预测1（抽查 2 点复核）。Given 预测/最终电价越出 [下限, 上限] When 钳制 Then 取边界值（抽查 1 点复核，09-08）。Given 24 点空间与 24 点预测 1/2 When 步骤四 Then 按 24 点序列同规则独立判定（抽查 1 时段复核，09-08）。Given 选中时段 + 历史运行日 When 检索 Then 相似运行日 = 该时段日前负荷率与计算负荷率差 ≤±5%（默认），输出落点档位概率与期望电价 = Σ(中值×概率)。Given 落点区间概率 When 灰度量价 Then 最低档 = 贴下限首档、最高档 = 贴上限末档，概率 = 落点概率，× 意向价差 × 量 → 最大收益/最大风险区间（抽查 1 时段复核）。Given N<3 When 展示 Then 仅"样本不足"。Given 修改边界/参数 When 重算 Then 预测 1/2、临界空间、落点概率/期望/灰度量价联动重出，旧结论留痕并列。

## §6b 火电开机 11 步推演算法（v1.7 新增，取代原 M7"最小出力 35% 规则化推开机空间"的简化口径；需求三）

> 目标：以 96 点逐点方式，在给定边界与正负备用/调频/受阻等约束下，推演出当日 96 点火电开机方式，并据此算出全省火电负荷率。**本算法为客观可复算算式，纳入 P-1c 客观层对照。开机支持"系统计算"与"人工自填"双模式（需求八）可切换。**

### 6b.1 输入变量（均受政策/行业/经营主体策略影响，交易员可自填，默认值见 §7 参数表）

| 变量 | 默认/建议 | 受什么影响（须可填） |
|---|---|---|
| 调频容量 | 1500（MW） | 受政策影响，应能自填 |
| 正备用 | 3000（MW） | 受政策影响，应能自填 |
| 负备用 | 400（MW） | 受政策影响，应能自填 |
| 受阻系数 | 10% | 受行业标准影响，应能自填 |
| 新能源平衡系数（96 点） | 建议默认风/光 ×0.8；可手动逐点改（见下） | 受风光大发时段消纳与报价策略影响，应能自填；不设极端/非极端自动判据 |
| 火电检修计划 | 当日检修容量（按机组/当日聚合） | 检修安排 |
| 零价负荷率 | 系统按**电价相似运行日出清情况（±5%）**预测一版（预测 + 理由），交易员可改（见下注）；**09-08：兼作 M8 步骤一"零价点负荷率"输入，推导 -100 临界火电竞价空间** | 经营主体报价行为可使其**大于**最小技术出力，故**不设"≤ 最小技术出力"上限**；随报价策略/时段变动，应能自填 |
| 最小开机方式 | 电网安全需维持上网的最小火电上网容量（应能自填） | 随供暖/非供暖等因素变动 |
| 辽宁火电装机容量 | 28715（MW，可能变动，应能自填） | 装机变化 |
| 当天火电最大可调/最大上网机组容量 | = 辽宁火电装机容量 − 当天检修计划（计算派生）= **当日火电开机的硬性上限（开机不得超出该值）**；检修计划可自填 | 检修/装机变化——**火电开机结果必须受此上限约束（保留，步骤 10 钳制上界）** |

**新能源平衡系数（v1.7；口径澄清 09-07）**：0:15–24:00 共 96 点；**平衡时段（建议默认）= 10:00–12:00、14:00–16:00、19:00–21:00**。平衡时段内风电、光伏分别乘一个折算系数，**建议默认风、光系数均 = 0.8**；**不设置"极端/非极端"自动触发判据**（系统不在极端与非极端场景间自动切换系数），该系数完全由**交易员手动设定**——可按平衡时段整体改、也可逐 96 点细改，修改值持久化（附录 D），缺省时采用建议默认 0.8。非平衡时段不折算（系数 = 1，亦由交易员可改）。

**零价负荷率（v1.7；口径澄清 09-07；09-08 兼作 M8 步骤一"零价点负荷率"输入）**：**不设"≤ 最小技术出力"上限**——经营主体的报价行为（低价/零价大量申报）很可能使某时段实际以零价出清的负荷率**大于**最小技术出力，故不再把零价负荷率硬约束为最小技术出力以内。取值方式（与预测层输出形态一致）：系统先按**电价相似运行日（±5%，09-08 由 ±3% 上调；该时段日前口径负荷率匹配）在该时段的出清情况**预测一版 96 点零价负荷率（**预测值 + 推导理由**，如"相似日 12:00–15:00 以零价出清的火电负荷率约 45%"），**交易员可手动修改/输入这版预测并附自己的理由**；系统版与修订版并列留痕（附录 D）。该值在 §6b.2 步骤 8 用于负备用校验，在 **M8 步骤一（09-08）用于推导 -100 临界火电竞价空间**（取 96 点负荷率 ≤ 零价点负荷率的点中火电竞价空间最大值），在下游价格落点概率/灰度量价中作为零价边界的依据，故其口径直接影响负备用校验结果、-100 临界空间与零价区间判断。

### 6b.2 推演步骤（逐点 96 点）

1. **计算 96 点每一时刻的火电竞价空间**：`火电竞价空间(t) = 负荷 − 水电 − 核电 − 地方燃煤 − 风电 − 光伏 − 联络线 − 非市场化出力`（均 96 点逐点）。
2. **计算 96 点"折算新能源系数"的火电竞价空间**：
   - 对**平衡时段**：`火电竞价空间(t) = 负荷 − 水电 − 核电 − 地方燃煤 − 风电×平衡系数 − 光伏×平衡系数 − 联络线 − 非市场化出力`；
   - 对**非平衡时段**：同第 1 步（不折算）。
3. **计算"正备用 + 调频所需开机"（96 点可逐点/常量）**：`正备用+调频所需开机 = (正备用 + 调频容量) / (1 − 受阻系数)`。
4. **计算"增加备用后火电所需开机"（96 点逐点相加）**：`增加备用后火电所需开机(t) = 折算新能源系数的火电竞价空间(t) + 正备用+调频所需开机`（每点分别相加）。
5. **未校验的当日最大开机**：对 96 点"增加备用后火电所需开机"取最大值，记为 `未校验的当日最大开机`；**作为暂定全天 96 点开机**——96 个点位每个都暂定为该值（火电开机按"当日一次开停 + 全天恒开机水平"的粗口径，先取全日统一开机）。
   - **校验环节（6–10）**：注意，校验环节**不使用 96 点折算新能源系数的竞价空间，而使用未考虑新能源折算系数的 96 点每一时刻火电竞价空间**——**扩大安全性考虑**。
6. **验证正备用（96 点逐点）**：
   - `该时段剩余正备用(t) = 暂定全天96点开机 × (1 − 受阻系数) − 96点每一时刻的竞价空间 − 受阻系数`；
   - `该时段剩余正备用盈余(t) = 该时段剩余正备用(t) − 定义正备用(3000)`；
   - 若某时刻剩余正备用盈余 < 0，说明该时段正备用不足，**需增加开机**。
7. **正备用盈余不足部分增添开机**：对校验中正备用未达要求的时段（盈余为负），计算需额外增添的：`正备用盈余不足部分增添开机 = |剩余正备用盈余| × (1 − 受阻系数)`。
8. **验证负备用（96 点逐点）**：
   - `该时段剩余负备用(t) = 96点每一时刻的竞价空间 − (暂定全天96点开机 × 零价负荷率)`；
   - `该时段剩余负备用盈余(t) = 该时段剩余负备用(t) − 定义负备用(400)`；
   - 若某时刻剩余负备用盈余 < 0，说明该时段负备用不足，**需减少开机**（v1.7 澄清：负备用不足是"减开机"，非"增开机"——原需求条文此处笔误已按物理含义纠正）。
9. **负备用盈余不足部分减少开机**：对校验中负备用未达要求的时段，计算需额外减少的：`负备用盈余不足部分减少开机 = |剩余负备用盈余| × (1 − 受阻系数)`。
10. **计算验证正负备用后的 96 点开机**：
    `验证正负备用后的开机(t) = 未校验的当日最大开机 + 正备用盈余不足部分增添开机 − 负备用盈余不足部分减少开机`；
    钳制（逐点）：
    - 若 `验证正负备用后的开机(t) ≥ 当天火电最大上网容量`（= 装机容量 − 检修计划）→ 取 `当天火电最大上网容量`；
    - 若 `验证正负备用后的开机(t) ≤ 最小开机方式` → 取 `最小开机方式`。
11. **最终开机预测（考虑日内一次启停）**：考虑辽宁通常**一天一次日内启停**，分上/下午两段分别取该段内"验证正负备用后的开机"的最大值，作为该段全部时点的最终开机预测：
    - **上午段**：0:15–12:45；**下午段**：13:00–24:00（对应 96 点第 1–51 点与第 52–96 点）。
    - `上午段最终开机 = max(验证后开机(t∈上午段))`；`下午段最终开机 = max(验证后开机(t∈下午段))`；该段所有时点的最终开机预测均定义为对应区间的最大值。
    - **注（业务方口径）**：为什么取对应区间最大值？——**火电不能随意启停，优先保证正备用**；负备用不足导致的电能消纳负担**通过负电价回收**消化，故不因个别负备用时段而拉低开机水平。
- **全省火电负荷率（96 点，v1.7 口径澄清 09-07）**：`负荷率(t) = 该点火电竞价空间(t) / 计算出的该点火电开机(t)`——**分子取该点时点未折算新能源系数口径下的火电竞价空间（即该时段电网需火电承担的出力），分母取最终 96 点开机（上/下半日恒值、经钳制校验后的开机）**。其中：
  - **参考装机口径统一为辽宁火电装机 28715 MW**（不再保留"全省约 2,900 万"参考口径），且**辽宁装机容量本身交易员可自填修改，以适配未来装机增长**（§6b.1 已注明"可能变动应能自填"）。
  - **不再以"最小出力 35%"作为分母技术上限口径**（原 M7 简化"最小出力 35% 规则化推开机空间"取消，§6b 由 11 步推演直接得到开机，无需再除以 35% 推出"开机空间"）。
  - **【口径澄清（09-07）：装机−检修未删除，仍为开机硬上限】**：被取消的只是"装机−检修当日可调**作为负荷率分母**"这一层语义；**`当天最大可调 = 辽宁火电装机 28715(可自填) − 当天检修计划` 仍作为火电开机结果的硬性上限保留——任何时点的开机不得超出它（步骤 10 钳制上界，见 §6b.1 变量行与步骤 10）**。即：装机−检修用于"约束开机、不上限负荷率"，两者角色不同。
  - 该口径下负荷率 = 火电需承担出力 ÷ 开机容量，物理含义是"开机机组需压到的平均负荷水平"；数值可 >100%（个别低谷点竞价空间高于开机容量时的短时预警信号，用于提示是否需要追加开机或调峰），不做硬性拦截（区别于 §6b.4 中对"明显异常"的拦截）。**96 点火电负荷率 → 96→24 合成 24 点负荷率**供 M8（09-08：M8 用电竞空间直接驱动电价预测公式与 -100 临界判定；负荷率用于零价点负荷率比较与 ±5% 相似运行日检索）。

### 6b.3 双模式（需求八）
- **系统计算模式（默认）**：按上述 11 步自动推演；可修改任一输入变量后重算。
- **人工自填模式**：交易员直接录入当日 96 点（或上/下半日恒值）火电开机；系统不覆盖人工值；人工版与系统版**并列留痕、可切换**（附录 D）。
- 两种模式切换不丢另一模式结果。

### 6b.4 异常与缺参
- 调频/正备用/负备用/受阻系数/零价负荷率/最小开机方式/辽宁装机/检修计划任一缺 → 该参数标"缺"，按"人工自填模式"或"默认值 + 黄警示"继续，不产无标注猜测值（沿用补齐策略）；负荷率出现**持续性 >100%（而非个别低谷点短时）**或明显异常 → 黄警示/拦截提示，提示交易员核对开机或竞价空间（个别时点 >100% 属"开机需压更高的信号"，不硬拦，见 §6b.2 负荷率口径）。
- 火电开机推演属客观可复算，纳入 P-1c；与老 Excel / 人工开机读数同口径比对（无则列口径差异清单）。

## §6c 人工边界修订持久化与数据存储设计（v1.7 需求六；附录 D 为落地方案骨架）

> **问题**：对人工修改后的边界数据（如交易员把某边界从披露值改为自估值、把预测联络线改成自己的判断、录入意向价/开机参数等），**如何在不覆盖系统产出原数据的前提下妥善保存，并方便系统后续读取处理**。
> **原则**：**读时合并（原值永不物理覆盖），写时新增版本（append-only 修订链）**；任何人工修订都是一条新记录，系统原值作为独立版本保留。

- **分层存储**：一张"边界主表"存**系统产出原始值**（披露/推断/补齐，来源日、来源类型、计算版本）；人工修订写入**独立修订表**，不覆盖主表。
- **修订记录**：每条修订含 `(边界ID, 时点t, 原值引用, 修订值, 修订原因备注≥5字, 修订人, 修订时间, 依据, 状态)`；修订可叠加（按时间戳/版本串联成修订链），形成"原值 → 修订1 → 修订2…"可回退。
- **读取规则**：系统下游计算默认读"最新有效修订值"（未修订点位读原值）；对比/留痕视图读全版本。
- **回退**：可把某点位/某时段恢复到任一历史版本，恢复本身再记一条修订（不物理删除）。
- **入库一致性**：M1 装载 → 主表；后续各模块中间/输出量亦分层（系统版列 + 人工修订列），供 M9 曲线与决策链并列展示。
- 具体表结构与字段、外键、索引、版本控制见**附录 D**；MVP 阶段可用本地轻量库（SQLite 或 CSV 分层目录 + 元数据 JSON，数据不出内网）落地，不需引入外部 DB 服务。

## 附录 D：人工边界修订持久化与数据存储设计（v1.7 需求六，落地方案骨架）

> 目标：**人工修改后的边界数据，在不覆盖系统产出的原数据前提下妥善保存，并便于系统后续读取处理。**
> MVP 阶段建议**本地轻量落地**（SQLite 单库或 CSV 分层目录 + 元数据 JSON，数据不出内网），不引入外部 DB/云服务；本文给出表结构骨架，产品化时平移至正式数据库。

### D.1 核心原则
- **原值永不物理覆盖（append-only）**：系统产出（披露/推断/补齐/计算中间值）写主表/系统版，人工修订只追加新记录，绝不 UPDATE 主表原值。
- **读时合并、写时版本**：下游计算读"最新有效修订"（未修订读原值）；对比/审计视图读全版本。
- **修订必带元数据**：人、时间、原因（≥5 字）、依据、状态、被引用原值版本。
- **可回退**：恢复到任一所记录版本，恢复本身记为一次新修订（不物理删除）。

### D.2 主要表（字段骨架）
1. **boundary_master（边界主表·系统原值）**
   `boundary_id, date/run_id, period(时点 t 1..96), boundary_type(负荷/风光/核电/水电/地方燃煤/非市场化/联络线/省间量/开机/负荷率/电价…), value_type(披露/推断/补齐), src_day(来源日/来源文件), calc_version(系统计算版本), value(数值), created_at`
   - 主键 `(boundary_id, run_id, period, calc_version)`；**只 INSERT，不 UPDATE**。
2. **boundary_revision（人工修订表）**
   `rev_id, boundary_id, run_id, period, ref_master_version(引用主表/上一版), revised_value, reason(≥5字), evidence(依据), operator, op_time, status(有效/已回退), prev_rev_id(修订链上一版)`
   - 构成**修订链**（prev_rev_id 串联），读取"最新有效"即链尾 status=有效者。
3. **intent_input（意向输入表，v1.7：挂牌/摘牌价、意向交易量、开机参数覆盖）**
   `item_id, run_id, period(或常量), item_type(意向挂牌价/摘牌价/交易量/调频/正负备用/受阻/新能源系数/检修/零价负荷率/最小开机方式/装机…), value, revised_flag, ref_master, reason, operator, op_time`
4. **calc_run（计算版本表）**
   `run_id, date, calc_mode(系统开机推演/人工自填开机), params_snapshot(参数快照), m7_mode, created_at, status`
   - 记录"用了哪套参数/哪种模式"产出当前结果，保证可复现。

### D.3 读取/合并规则（供系统后续读取）
- 计算输入：`effective_value = 最新有效修订(boundary_revision) 若无修订 → boundary_master 系统原值`。
- 曲线/留痕视图：任一时点同时取"系统原值 + 各修订值"，供并列展示与回退。
- 快照留痕（策略环节 §5.4b、对照报告）：以 `calc_run + 各表当前链尾` 为准，写入留痕记录，保证版本可追溯。

### D.4 覆盖人工写入的边界对象（v1.7 范围；09-08 扩展）
- 边界：省调负荷、各电源出力（含核电预测 min 口径）、联络线、省间量、火电开机、负荷率、价格/电价落点区间概率所依据的历史电价修正等。
