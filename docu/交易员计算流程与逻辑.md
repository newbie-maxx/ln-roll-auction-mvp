### 0.5 日期角色（已确认）

- **D 日 = 08-31**（预测对象日）
- **A 日 = 08-30**（= 数据库中最新日前出清价所在日）
- **A-1 日 = 08-29**（A 日前一运行日；若其 96 点电价 ≤0 的点 >48 → 向前回溯 08-28、08-27…，直到满足 ≤48）
- **历史日 = 08-01…08-30**

## 1. M1 装载（PRD §6.1 M1）

- **多格式 loader**（CSV/XLSX/PDF）→ 统一中间格式 → 校验入库；**loader 可替换**（B 轨仅换 loader 接外部通道，计算零改动）。全程离线，无任何联网/接口/抓取。
- **96 点入库**；省内边界原生 96 点；省间滚撮 24 点 **24→96 展开 = 同一小时值复制 4 份**。
- **三类标注**：披露 / 推断 / 补齐（+ 来源日）。推断/补齐不得冒充披露。
- **运行日不可披露项**（非市场化 / 水电 / 地方燃煤）→ **最近日法**：取最近一期披露值近似替代运行日值并标注来源日；历史日按各自披露值入链。
- **缺数补齐顺序**：人工填数 → 相似日 → 均值/插值；有据标注 `▣补齐(方式+依据)`，无据标"缺输入"（不产猜测值、不阻塞链路）。
- **核电预测** = `min(最新披露运行日出力, 检修计划出力上限)`；检修计划未覆盖机组上限 = 额定/披露出力；检修数据缺 → 未检修默认开机（额定出力）+ 标注假设。取值依据标 `最近披露 M-D` / `检修上限`。
- **人工输入并入**：意向挂牌/摘牌价（24 点，默认整日同值可改，标 `意向`；非数值或 ≤0 拒绝）；火电开机参数组（§7 参数表，可改留痕）。
- 文件缺列/行数不符 → 拒绝入库并提示差异项。
- 水电聚合口径 = 地方水电 + 抽蓄水电（v1.1 补充四）。

## 2. M2 分布式推断（PRD §6.2 M2）

- 分布式光伏、分散式风电：各挑**集中式风光最相近历史日**取值，标 `▣取自 M-D`。
- 来源日必须为历史日；查不到相近日 → 标"缺"；推断无标注不展示。
- 气象平台接口预留（光照/温度旁证，本次不接公网，不阻塞）。

## 3. M3 相似日检索（PRD §6.1 M3）

- **A 维度算式（v1.4，业务方 09-04 更正）**：
  `A(t) = 省调负荷 − 新能源出力 − 核电出力 − 水电出力 − 非市场化出力 − 地方燃煤出力`
  （= 火电竞价空间 + 联络线出力，联络线项被消去，历史日与运行日两侧均可直接计算。新能源出力 = 风电 + 光伏；核电采用 M1 核电预测 min 口径，避免二义。）
- **逐 96 点点位**检索历史样本组（A 维度 + 新能源维度各一版）；显示 N、成员、分布（中位/P25/P75）、跨月标注 `▣`。
- **N ≥ 3 才给分布**；N < 3 自动放宽至上一周并标注"已放宽+统计范围"；N = 0 无样本。
- A(t) 任一项缺 → 先按补齐策略处理，仍无据标"缺输入"、不出值。

## 4. M4 基线（PRD §6.2 M4；符号口径 2026-09-10 修正）

- 各历史日基线(96 点) = `日前联络线 − 省间滚撮量(24→96 展开)`（滚撮正 = 买入/受入，买入压低基线）。【原 PRD 为"+ 滚撮量"，随符号口径锁定更正】
- 缺数据日标"缺"**不参与均值**；负值/越界拦截；无任何历史 → 下游不出值。
- 展开抽查口径：96 点连续 4 点 = 同一 24 点值。

## 5. M5 省间交易总数（PRD §6.1 M5）

- 省间交易总数 = `滚撮量(24→96 展开) + 省间现货`。
- **省间现货恒等式自算（不爬取）**：`历史日省间现货 = 日前联络线 − 实时联络线`（compute_spot）；运行日现货为辅助推测（预测层，带把握说明）。**"历史日自算省间现货"作为边界展示项一并展示。**
- 滚撮值携带抓取/快照时刻标注；某点位未录滚撮值 → 仅用现货项 + 黄色警示（不把"0 成交量"当"已成交 0"）。
- 更正必填备注 ≥5 字，联动重算留痕。
- 意向挂牌/摘牌价录入（24 点，标 `意向`，供 M8 灰度量价）。

## 6. M6 预测联络线（PRD §6.1 M6）

- `预测联络线(96 点) = 基线均值 − 省间交易总数`（考核量产出；恒等式两侧可复核）。
- 输出标 `推断值` + 理由；中间值（基线均值、省间数、样本来源）随行输出。
- 人工修改必填理由 ≥5 字，系统版/修订版并列留痕。
- 基线或省间任一缺 → 该点位"缺输入"，不出值。

## 6b. 实时联络线预测（2026-09-10 新增口径）

- 边界「联络线」显示名为**联络线基线**（数据同日前联络线，可改）。
- 新增可改输入**省间交易总量**（交易员预测 = 省间滚搓 + 省间现货）：**24 点、默认全 0 待交易员更新**；**符号：正 = 买入/受入，负 = 卖出/送出**；计算时自动 24→96 展开（小时值复制 4 份，**功率值不除以 4**）；编辑任一点即整小时 4 点同值。
- `实时联络线预测(96) = 联络线基线(96) + 省间交易总量(96 展开)`。
- **运行日（D 日）火电竞价空间的联络线项 = 实时联络线预测**（M6 预测联络线仍作考核参考输出保留）。

## 7. M7 开机与负荷率（PRD §6b，11 步推演）

**火电竞价空间**：`火电竞价空间(t) = 负荷 − 水电 − 核电 − 地方燃煤 − 风电 − 光伏 − 联络线 − 非市场化出力`（96 点逐点；**运行日"联络线"项 = 实时联络线预测**，见 §6b）。

**11 步推演（§6b.2 逐条照抄）**：

1. 计算 96 点每一时刻的火电竞价空间（上式）。
2. 计算 96 点"折算新能源系数"的火电竞价空间：平衡时段（建议默认 10–12/14–16/19–21）`负荷 − 水电 − 核电 − 地方燃煤 − 风电×平衡系数 − 光伏×平衡系数 − 联络线 − 非市场化出力`；非平衡时段同第 1 步（不折算）。
3. `正备用+调频所需开机 = (正备用 + 调频容量) / (1 − 受阻系数)`（96 点可逐点/常量）。
4. `增加备用后火电所需开机(t) = 折算新能源系数的火电竞价空间(t) + 正备用+调频所需开机`（逐点相加）。
5. `未校验的当日最大开机 = max(96 点"增加备用后火电所需开机")`，作为暂定全天 96 点开机（当日一次开停 + 全天恒开机粗口径）。**校验环节（6–10）不使用折算空间，而使用未折算的 96 点每一时刻火电竞价空间（扩大安全性考虑）。**
6. 验证正备用（逐点）：`该时段剩余正备用(t) = 暂定全天96点开机 × (1 − 受阻系数) − 96点每一时刻的竞价空间`；`盈余(t) = 剩余正备用(t) − 定义正备用(3000)`；盈余 < 0 → 正备用不足，需增加开机。
   > 【业务方 2026-09-10 更正】原 PRD 尾部"− 受阻系数"为笔误（量纲 MW vs 百分数），已去除。
7. `正备用盈余不足部分增添开机 = |剩余正备用盈余| ÷ (1 − 受阻系数)`（对盈余为负的时段）。
   > 【业务方 2026-09-10 更正】原"× (1 − 受阻系数)"为笔误，改为除以。
8. 验证负备用（逐点）：`该时段剩余负备用(t) = 96点每一时刻的竞价空间 − (暂定全天96点开机 × 零价负荷率)`；`盈余(t) = 剩余负备用(t) − 定义负备用(400)`；盈余 < 0 → 负备用不足，**需减少开机**（v1.7 澄清，原条文"增开机"为笔误已纠正）。
9. `负备用盈余不足部分减少开机 = |剩余负备用盈余| ÷ (1 − 受阻系数)`。
   > 【业务方 2026-09-10 更正】原"× (1 − 受阻系数)"为笔误，改为除以（与⑦同口径）。
10. `验证正负备用后的开机(t) = 未校验的当日最大开机 + 正备用增添开机 − 负备用减少开机`；逐点钳制：`≥ 当天火电最大上网容量(装机 − 检修)` → 取该上限；`≤ 最小开机方式` → 取最小开机方式。
11. 最终开机（日内一次启停）：上半日第 1–51 点（0:15–12:45）、下半日第 52–96 点（13:00–24:00）**各取段内 max** 为该段全部时点最终开机。取 max 理由（业务口径）：火电不能随意启停、优先保证正备用，负备用不足通过负电价回收消化。

**负荷率**：`负荷率(t) = 该点火电竞价空间(t) / 计算出的该点火电开机(t)`——分子 = **未折算**口径火电竞价空间，分母 = 最终 96 点开机（上/下半日恒值）。参考装机口径 = 辽宁装机 28715（可改）；装机−检修仅作开机钳制上界、不作负荷率分母；负荷率可 >100%（个别低谷点预警信号，不硬拦；持续性 >100% → 黄警示/拦截）。

**96→24 合成**：24 点负荷率 = 每 4 点算术平均。

**双模式**：系统计算（默认）/ 人工自填（96 点或上/下半日恒值），两版并列留痕、可切换、互不覆盖。

**缺参**：任一参数缺 → 标"缺"，按人工自填或"默认值 + 黄警示"继续，不产无标注猜测值。

## 8. M8 电价预测（PRD §6.1 M8，09-08 确定性算法）

日期定义：**A 日 = 数据库最新日前出清价所在日**；**A-1 日 = A 日前一运行日**，须满足"电价 ≤0 的点 ≤48 点（96 点粒度）"，否则向前回溯（A-2、A-3…）直到满足（仅约束拟合日 2，A 日不设限）。

- **步骤一（-100 临界火电竞价空间）**：D 日 96 点负荷率 = D 日空间 ÷ 开机（M7 产出）；取 负荷率 ≤ 零价点负荷率 的点中**火电竞价空间最大值** = -100 临界空间（低于它的点预计按现货下限定价）。
- **步骤二（拟合两版）**：
  - 拟合日 1 = A 日（放缩）：`k = A 日空间最大值 ÷ D 日空间最大值`；`A 日归一空间 = A 日空间 ÷ k`；对（A 日归一空间, A 日 96 点日前电价）一次线性拟合 → **M1、C1**。
  - 拟合日 2 = A-1 日（回溯满足条件；不缩放）：对（A-1 日原始空间, A-1 日 96 点日前电价）一次线性拟合 → **M2、C2**。
- **步骤三（预测 1/2）**：`预测1 = M1×D 日空间 + C1`；`预测2 = M2×D 日空间 + C2`。96 点版用 96 点空间；24 点版独立：`24 点空间 = 每 4 点等权算术平均`，代入同公式（两版各自独立，不强制 24 点 = 96 点聚合）。
- **钳制**：预测 1/2 与最终电价统一钳制 `[现货下限, 现货上限]`（默认 -100/1500，随参数），越界取边界值。
- **步骤四（最终电价，逐点判定）**：
  1. 该点 D 日空间 ≤ -100 临界空间 → 该点电价 = **现货市场出清价格下限参数值**（默认 -100，与钳制同源；v1.8 回改"固定 -100"）；
  2. 否则看**预测 1 全序列最小值 < 10（固定值，不随参数联动）**：是 → 空间 > 临界的点**整体**取预测 2；否 → 取预测 1。
  24 点版以 24 点空间与 24 点预测 1/2 执行同一规则独立判定。
- 预测电价 96+24 均为**只读输出**。

## 9. M8 落点区间概率与期望（相似日唯一用途）

- 对交易员**选中的时段**（24 点口径）：在选定历史日范围内检索**该时段日前口径负荷率与 D 日计算负荷率差 ≤ ±5%**（默认可改）的运行日。
- 取这些运行日**该时段实时出清价**，按区间宽度将 `[现货下限, 现货上限]` 分等宽档位，统计落档概率（**分子/分母/统计范围同显**）。
- `电价期望 = Σ(各档区间中值 × 该档概率)`。
- **N < 3 → 仅"样本不足"**，不出概率。
- 历史日"日前口径负荷率"来源 = 24点平均日前负荷率 sheet（本地导出兜底）。

## 10. M8 灰度量价

- `最低落点区间 = [现货下限, 下限 + 区间宽度]`（贴下限首档）；`最高落点区间 = [上限 − 区间宽度, 上限]`（贴上限末档）；概率 = 该档落点概率（可为 0）。
- `最大收益/最大风险价格区间 = 最低/最高落点区间两端与意向挂牌/摘牌价相减`；`× 交易量 = 带灰度的金额区间`；概率与落点概率相等。
- 缺意向价/量 → 提示"缺意向价/量，不评估收益风险"。
- 方向语义（挂牌卖/摘牌买对收益亏损符号）以滚撮"价差撮合"口径为准，待业务方校正后锁定（登记项）。

## 12. M9 工作台要点（PRD §5.4a）

- **一屏三栏**：左 24 时段导航（预测价/意向价/预估负荷率 24 点合成值三值 + 选中高亮）；中 展示区（可改边界 96 点曲线 + 数值格；只读派生/输出）；右 智能助手常驻对话框。
- **展示对象可改性三类**：① 可改边界 96 点（省调负荷/集中风光/核电/水电/地方燃煤/非市场化/联络线/火电开机）；② 只读派生（负荷率 96+24 平铺）；③ 只读输出（预测电价 96+24 平铺[最终/预测1/预测2]、落点概率/期望/灰度 24 点）。
- **右滑面板**（点左栏时段触发）：仅覆盖中栏、左右栏常驻；全天 96 点曲线+数值格，**仅该小时对应 4 点可改（标红）**、余 92 点只读；意向价/交易量 24 点录入；只读明细区。
- **颜色语义**：披露 = 实线蓝/黑；测算 = 虚线橙 + `推断/计算/取自 M-D` 标注；输出 = 独立紫色徽标（不进披露/测算双色体系）；选中时段 = markArea 标红（与可改性分离）；修订曲线 = 绿色与原曲线并存。
- **修订**：数值格并列原值/新值/理由（必填，【2026-09-10 调整】不限字数）；append-only 修订链（附录 D），原值永不覆盖、可回退（回退本身记新修订）。
- **联动重算**（§8 主指标）：任意改动（全局参数/边界点/意向价/上下限/宽度/±5%/零价点负荷率）→ 全量 ≤30s、单点 ≤1s；只读输出仅在联动中刷新，无修订并存。
- **预测层形态**：一版预测 + 理由；修订版附理由；两版并列留痕（附录 D）。
- **策略助手（右栏）**：只评审不代拟、不产可申报数值（护栏 G4）；每轮快照留痕（D15：输入快照 + 工具调用序列 + 回答 + 时间/版本落 chat_log）。
- 导出：表格/CSV（披露/测算标注 + 来源日），供留档与对照。
